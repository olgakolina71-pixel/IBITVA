# IBITVA Studio

Free, offline Android music sketch studio: touch piano-roll, synth, beat maker and WAV export.

## Features (v0.1)
- 16-step piano roll, tempo control and four sound colors
- Synthesized playback and drum-style notes
- Project save locally and WAV rendering
- Android APK built with GitHub Actions

Open in Android Studio (JDK 17, SDK 35), or build with `gradle :app:assembleDebug`.
APK output: `app/build/outputs/apk/debug/app-debug.apk`.
